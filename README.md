# C&K Courtesy Cleaners website

A multi-page Next.js website starter for C&K Courtesy Cleaners.

## Requirements
- Node.js 20.9+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production checks
```bash
npm run typecheck
npm run build
npm start
```

## Before launch
1. Replace the illustrative photography with approved C&K photographs.
2. Confirm current services, opening hours, contact details and management-approved company history.
3. Add the existing official logo at `public/ck-logo.svg` (or update the header to use the supplied asset).
4. Replace the Google review link placeholder with the correct Google Business Profile review URL.
5. Configure a production contact-form delivery service. The current form opens the visitor's email application as a no-backend fallback.
6. Confirm legal/privacy requirements and add the final privacy policy.
7. Verify the canonical domain and redirect legacy URLs before deployment.

## Notes
- No customer reviews, ratings, opening hours, prices or service guarantees are fabricated.
- Photography currently uses remote Unsplash images as temporary visual placeholders, not photographs of C&K's premises or work.
- Some service routes are included as proposed content structure; management must confirm current availability before publishing.
